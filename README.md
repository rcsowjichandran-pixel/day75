# Petal Portfolio Builder

A pastel-themed React app for creating a personal portfolio. Add your profile,
skills, projects, and email, choose a visual theme, then generate a responsive
portfolio preview. Use **Back to Form** to continue editing.

## Getting started

```sh
npm install
npm run dev
```

## Checks

```sh
npm run build
npm run lint
```

The app uses Vite, React, and Tailwind CSS via the Tailwind Vite plugin.
